# Malak Hamdy - Personal Portfolio Website

A modern, elegant, and fully responsive personal portfolio website crafted for **Malak Hamdy**, an aspiring Creative Designer and Content Creator based in Alexandria, Egypt.

## 🎨 Theme & Aesthetic Palette
- **Primary Brand Color**: Deep Royal Purple / Violet (`#5B1363`, `#450D4B`)
- **Accent Tints**: Soft Lavender & Lilac (`#F5EEF7`, `#EBD7F0`, `#DFC1E6`, `#7B1FA2`)
- **Main Background**: Pure Clean White (`#FFFFFF`)
- **Card Backgrounds**: Subtle Light Gray / Off-White (`#FAFAFC`, `#FFFFFF`) with crisp light borders (`#ECE8F0`)
- **Typography & High Contrast**:
  - Headings: Deep Charcoal / Black (`#222222`)
  - Body Text: Clean readable Gray (`#555555`)
  - Accent Keywords: Deep Royal Purple (`#5B1363`)

   - Features Malak's real personal photo (`personal_photo.jpg` / `malak-profile.jpg`).

   - Royal purple gradient box showcasing Malak's vision statement and growth milestones.

7. **Contact Section & Real-time Validation**:
